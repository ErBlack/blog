Today we'll be drawing Budapest, specifically the Hungarian Parliament Building, Országház.

I really enjoy drawing buildings because by performing a large number of very simple actions, you can achieve an impressive result. You draw many sticks, circles, and triangles, and then look at what you've created and are amazed. The only drawback is that it takes a lot of time. I couldn't finish this picture in one sitting. So grab some coffee, turn on some music or an audiobook, and let's begin.

First, we'll make a . This is necessary to see the main parts of the building. I've noticed that to truly see something, it's not enough to just look at it. When you try to draw it, you see twice as much.

From the draft, we can understand what the building consists of, and we can start drawing the foundation. At this point, be careful not to overdo the vertical details. In general, all buildings have vertical and horizontal rhythms that divide the building into layers. The foundation will set the main vertical guidelines. Left, right, and central towers in the foreground, and what's between them in the background. The background lines in the foundation are positioned slightly lower. If we take the width of the central tower as 3, then the width of the outer ones will be about 2, and the connections about 4.

Now let's draw the central tower. It will set the horizontal guidelines. Start from the bottom up, like a layered cake. A separate picture shows the layers it consists of. Each horizontal layer is divided into 9 vertical sections. At the intersection of layers are windows, arches, or turrets.

Next are the wings. There are large arches that will set the vertical rhythm. There are 14-15 arches. The middle tower, which is 5 arches wide, starts 4 arches away from the central tower. A staircase 3 arches wide goes down from it.

The side turrets are left. They consist of 5 repeating vertical patterns.

The main thing is not to rush. Line by line, arch by arch, and it will all come together.
